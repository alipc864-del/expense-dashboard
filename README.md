# 📊 Expense Dashboard

A modern and responsive expense dashboard built with HTML, CSS and JavaScript.

## ✨ Features

- 💰 Track income and expenses
- 📊 Display total balance
- 📈 Income and expense overview
- ➕ Add transactions
- 🗑️ Delete transactions
- 🔍 Search transactions
- 💾 Save data with LocalStorage
- 📱 Responsive design
- 🌙 Modern dark UI

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🚀 About

This project was created to practice JavaScript, DOM manipulation, LocalStorage, transaction management and dynamic dashboard interfaces.
